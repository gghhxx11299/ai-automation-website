# AutoCallAI - AI Communication Automation Platform

A modern, tech-savvy website for an AI phonecall, email, and WhatsApp automation service. This project showcases cutting-edge web design with engaging animations and interactive elements.

## Features

- **Responsive Design**: Works seamlessly on all devices
- **Modern UI/UX**: Clean, professional interface with tech-savvy aesthetics
- **Interactive Elements**: Animations, hover effects, and dynamic content
- **Performance Optimized**: Fast loading and smooth interactions
- **Complete Pages**:
  - Home page with hero section and feature highlights
  - Pricing page with interactive toggle
  - Support resources page
  - FAQ with search and filtering
  - Contact page with validation

## Technologies Used

- HTML5
- CSS3 (with modern features like Flexbox and Grid)
- JavaScript (ES6+)
- Typed.js for text animations
- ScrollReveal for scroll animations
- Font Awesome for icons
- Google Fonts (Inter font)

## How to Use

1. Clone or download this repository
2. Open `index.html` in your preferred web browser
3. Navigate through the different pages to explore the website

## Customization

To customize the website for your own use:

1. Update the content in HTML files (text, images, links)
2. Modify colors in `css/style.css` by changing the CSS variables
3. Adjust animations in the JavaScript files
4. Update the contact form handling in `js/contact.js`
